# Preregistration for the proposed research stage

This protocol is frozen in an isolated preparation branch before any new
research outcomes are run or inspected. Integrate the research implementation
only after Part B passes its comparison. Do not change any old configuration,
seed, scenario or default forecaster. Proposed methods remain experimental.
No new AIS or synthetic outcome has been inspected in choosing these settings.

## Common rules

- C1 uses seeds 0 through 39, the main suite's eight history epochs, two-epoch
  horizon, four Gaussian sensors (rho .95, r 1), candidate spacing 1,
  planning grid 120 x 64 and evaluation grid 360 x 192.
- Candidate strategies are pooled, recent, drift_u, trend, stacked, pseudo_bma
  and oracle. Keep existing component-sampled negative results untouched.
- New result folders and configs only. Report all results, including losses.
- Paired differences use identical histories and truths. Bootstrap seed
  differences with the existing bootstrap_ci function and its fixed RNG.
- No claim that passing a finite experiment proves calibration or novelty.

## C1: shifts outside the candidate families

All lane widths, total rates and observation noise match the main framework.
Five new regimes:
1. accelerating: p(t)=p0+.1 t+.5*.06 t^2;
   alpha(t)=alpha0+.008 t+.5*.002 t^2.
2. rotating_quadratic: alpha(t)=alpha0+.05 t; p(t)=p0+.04 t^2.
3. random_walk: p offsets are cumulative N(0,.45^2) increments, generated by
   an independent RNG stream [scenario_seed, 314159]. Heading stays fixed.
4. random_switch: a +2.5 offset step at an integer epoch uniformly selected
   from 4 through 9, with independent RNG [scenario_seed, 271828].
5. lane_split: one lane becomes two equal-share lanes at epoch 5;
   centres move apart at +/-.65 offset units per epoch thereafter.

Use scenario_seed equal to replicate seed only in these new configs.
Primary metric: expected-detection percentage-point gain stacked minus pooled.
No success threshold: all wins and losses count as evidence.

## C2: diagnostics of the latent intensity sample law

For each sample-bearing field, evaluate each sample's expected missed mass
at the selected plan on the planning grid, and evaluate true expected missed
mass on that same grid. Record empirical midrank (strictly less plus half
exact ties, divided by number of draws), central 90% equal-tail coverage,
interval endpoints, true loss and sample count. Also record relative L1
mismatch of sample-mean intensity from the field's declared mean.

This is an ensemble rank/latent-intensity coverage diagnostic. It is NOT the
PIT of realised Poisson counts, calibration of the full point-process law,
or an operational sensor-validation result. Main calibration comparisons
use expected-objective plans; nonlinear-objective rows remain supplementary.

## C3: sampler candidates and a gate fixed before C1 results are viewed

Design and freeze candidate scripts using only the original model-matched
regimes and the previously seen audit. Do not inspect C1 test outcomes first.
Current component sampler stays the control and remains runnable.

Candidate W: independent within-component resampling of 32 field draws,
weighted by the existing stacking weights. Components without draws contribute
their deterministic mean. RNG [replicate seed, 1337, model index]. Field density
and expected-objective plans stay unchanged. The draw mean need not exactly
match the declared point forecast at finite ensemble size; measure that error.

Candidate R: whole-field multiplicative residuals from the chronological
lead-two backtests (targets 5,6,7 with prefixes 4,5,6). Observations are KDE
fields fitted with bandwidth learned on the prefix. Ratio denominator floor
is 1e-12 times max(mean prefix density, 1). Normalise the three residual factors
cellwise to mean one; sample factors uniformly with replacement, preserving
spatial dependence within each residual field. Residual bootstrap RNG is [replicate seed, 7331]; use the same
prefix-trained density floor in numerator and denominator. This is an experimental
empirical error law, not a posterior or an established calibrated distribution.

Evaluate candidates on the expected-objective stacked plans in all five C1
regimes. A candidate is eligible for further study only if every regime has
coverage at least .80, mean empirical rank in [.35,.65], and mean relative L1
sample-mean mismatch at most .10. No threshold changes or selective scenarios.
If neither passes, adopt neither. Continue recommending expected-loss planning;
keep existing void/CVaR results explicitly uncalibrated sensitivity analyses.
Do not run new nonlinear planning as if a failed candidate were calibrated.

## C4: common-estimator AIS reanalysis

Exploratory reanalysis of the already seen one-day sample, not a fresh holdout.
For pooled/recent/stacked KDE, multipliers [.25,.5,1,2,3] are a frozen grid.
At each test origin T, score each candidate scale using placement miss rate
on training-only rolling targets 3 through T-1, with forecasts fitted to each
prefix. Use test-line-count weighted validation loss and choose the first
smallest-loss scale (ascending multiplier order). Refit at T, then score T.
Scale bandwidth fits at EACH nested prefix, never freeze a final-fit bandwidth
across inner stacking validation. Cache only identical prefix/method/scale
fits. Keep all four per-origin results and chosen scales. No population claim.

## C5: geometry-aware transport ambiguity, exploratory small-grid study

Use the line metric d(i,j)=min over s in {-1,+1} of max over window corners
of |(n_i-s*n_j).x-(p_i-s*p_j)|. It is the quotient of a sup-norm distance
between signed line-distance functions, not an angular Euclidean metric.
Finite-grid equal-total W1 ambiguity. Check the scalar dual worst-case loss
against an independently written transport LP on small fixtures.

Seeds 0 through 19, scenarios stationary, drift, lane_shift, emergence,
reversal, seam_drift. Eight training epochs, horizon two, four sensors,
planning grid 20 x 12, evaluation grid 120 x 64, candidate spacing 5.
Use the same candidates and nominal KDE stacking for all plans. Compare
nominal, TV and W1 with greedy + swap from nominal and robust starts.
Calibrate each radius to the .90 empirical quantile (higher method) of its
metric's chronological normalised forecast-to-observed-KDE errors on the
three training-only lead-two backtests. Three calibration points do NOT
provide a .90 coverage guarantee; report their count and observed holdout
coverage. Record future detection, on-grid certificate, truth-in-ball status
and plan changes. No pass criterion or superiority claim is assumed.

## C6: small AIS ablations

Show stacking/pseudo-BMA weights at every origin. Compare the original policy
with minimum three usable validation origins (otherwise pooled), relative
log-score floor 1e-6 times the model's active mean density, and both changes.
Use all original test origins. For relative-floor intensity stacking, each
component's density floor enters the convex combination and analytic gradient;
check its gradient independently. Old absolute 1e-12 policy remains default.
All ablations are experimental runners/configs, not replacements for defaults.
